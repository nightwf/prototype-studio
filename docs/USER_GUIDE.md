# Prototype Studio 使用教程

Prototype Studio 是一个多画布原型工作台：页面是项目级公共资产，可以同时出现在多个独立画布中；Codex 负责理解原始文档并在用户确认拆分方案后创建页面和画布。

> 当前是 MVP 版本，主要面向后台管理类 Web 系统（列表页、表单页、详情页）。预览在本机进行，不提供公网分享。

## 一、两种使用方式

| 方式 | 适合谁 | 能力 |
| --- | --- | --- |
| 桌面 App | 正式使用 | 创建/打开本地项目、读写真实文件、启动 Local MCP |
| 浏览器体验 | 快速演示 | 打开即玩内置“案件中台”示例，不能读写真实文件系统 |

给别人使用时，请用桌面 App。

## 二、打包并安装桌面 App

### 打包（在开发者电脑上执行）

前置条件：Node.js 20+、pnpm 10+、Rust 1.77.2+，macOS 需要 Xcode Command Line Tools。

```bash
pnpm install
pnpm --dir apps/desktop build        # 生成 .app
pnpm --dir apps/desktop build:dmg    # 生成安装镜像（可选）
```

产物位置：

```text
apps/desktop/src-tauri/target/release/bundle/macos/
  Prototype Studio.app
  Prototype Studio_0.1.0_aarch64.dmg
```

把 `.dmg`（或整个 `.app` 压缩包）发给对方即可。Windows 安装包需要在 Windows 电脑上执行同样的构建。

### 安装（使用者的电脑）

- macOS：打开 DMG，把 `Prototype Studio` 拖进“应用程序”。如果提示“无法打开，因为无法验证开发者”，右键点应用 → “打开”，确认一次即可（目前为本地签名，未上架 App Store）。
- 首次打开后，在“应用程序”里双击启动。

## 三、快速上手（桌面 App）

桌面 App 打开后是空工作台，需要先创建或打开一个本地项目；内置的“案件中台”示例只存在于浏览器体验模式。

### 1. 创建或打开项目

点击左上角项目名 → 选择：

- “创建新项目”：输入项目名称，选择保存位置，自动生成标准项目目录；
- “打开本地项目”：选择已经包含 `project.yaml` 的项目目录（例如别人发给你的项目文件夹）。

项目目录结构：

```text
项目/
  project.yaml          项目信息
  pages/                页面 DSL（唯一事实源）
  boards/               独立画布 DSL
  flows/  data/  assets/ 其他业务资产
  .prototype/           版本历史、审计、回收站
```

### 2. 从文档生成原型

把 DOCX、PDF、Markdown 或扫描件直接交给 Codex。Codex 会先在对话中列出拟建画布名称、每个画布的范围、页面清单和共享页面；你确认后，它才调用 Prototype Studio MCP 创建或复用公共页面并批量创建画布。Studio 内不保存、不上传，也不解析原始文档。

### 3. 编辑页面

- **点选修改**：在 Preview 里点击任意组件，右侧属性面板修改 Label、必填、可见、尺寸等，实时生效；
- **拖拽排序**：左侧组件大纲里拖动查询字段调整顺序；
- **页面管理**：页面树里新建（列表/表单/详情）、重命名、上移下移、删除（删除进回收站，可恢复）。

### 3·5. 画布（Axure 式大画布）

点击左侧“画布”后可查看项目中的全部画布；点击任意画布进入可缩放、可平移的画布模式：

- **新建画布**：创建空白画布，或勾选已有页面后按两列自动平铺；
- **画布管理**：支持重命名、修改说明、设为默认、移入回收站和从回收站恢复；项目至少保留一个画布；

- **页面对象**：页面以可拖动的页面帧出现在画布上，双击进入页面编辑；工具栏“页面”可把其他页面添加到画布；
- **说明**：工具栏“说明”添加说明卡片，右侧面板编辑文字；
- **标注**：两个入口——画布工具栏“标注”选择挂靠页面和组件后添加；或在“页面”编辑模式选中组件后，右侧面板点“添加标注（挂靠此组件）”直接添加。圆点可直接拖拽微调位置，右侧面板编辑颜色与文字；标注跟随组件移动，缩放不错位；
- **流程图 / ER 图**：工具栏“流程”“ER”添加，右侧面板编辑节点、连线、实体、字段与关系；
- **连线**：选中对象后在右侧面板选择目标对象，起点和终点可绑定到页面内的具体组件。点击画布上的连线可编辑说明、直线/曲线/折线、粗细和颜色；选中连线后可直接拖动两端锚点，重新吸附到其他页面或页面组件；
- **导出 HTML**：可导出当前画布，也可导出带顶部画布导航的全部画布自包含 HTML；
- 画布内容保存在 `boards/{boardId}.board.yaml`，每个画布使用独立版本链和保存队列；页面修改后，所有引用该页面的画布会同步显示最新内容。

### 4. 版本与撤销

- 每次修改都会生成一个不可覆盖的 Revision；
- 顶栏“版本”按钮查看 DSL Diff 和修改历史；
- 撤销/重做按钮可回退，历史记录依然保留。

### 5. 数据都在本地

- 关闭 App 不丢数据；把整个项目文件夹复制、压缩、发 Git，别人打开同一个文件夹即可继续；
- 外部直接修改 `pages/*.ui.yaml`，App 会自动重新校验并刷新 Preview；改坏时保留最后一个有效预览并提示错误位置。

## 四、让 Codex 参与（可选）

1. 打开一个桌面项目后，Local MCP 会自动启动（顶栏设置里可查看状态）；
2. 点顶栏齿轮“设置”，打开“设置 · 连接 Codex”面板；
3. 复制 Step 1 的 MCP 配置，粘贴到 `~/.codex/config.toml`（或在 Codex 设置 → MCP servers → Add server，类型选 STDIO），重启 Codex；
4. 复制 Step 2 的协作提示词，粘贴到 Codex 对话，告诉它如何使用这个本地项目；
5. 之后 Codex 可以读取项目、页面、组件，通过结构化命令参与修改；Codex 修改与手动修改共用同一版本链，可撤销、可审计。

> 注意：一个 MCP 配置实例只绑定一个项目（`PROTOTYPE_STUDIO_PROJECT_ROOT`）。多项目时在 Codex 里添加多个服务器。完整工具清单见 [apps/mcp/README.md](../apps/mcp/README.md)。

## 五、快速体验（浏览器模式）

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:4173`。可以体验点选编辑、撤销、多画布管理与画布导出。

## 六、常见问题

- **文档会保存在 Studio 里吗？** 不会。原始文档只在 Codex 对话中处理，Studio 只保存最终页面和画布。
- **页面太简单怎么办？** 模板生成的是最小可用骨架，后续通过点选编辑、命令栏或 Codex 逐步精修。
- **删错页面了？** 删除只是移入 `.prototype/trash/`，可从项目文件夹恢复。
- **预览打不开？** 浏览器模式需要 `pnpm dev` 保持运行；桌面 App 不需要额外服务。
